# Smart Expense Manager

Smart Expense Manager is a full-stack financial tracking application that
helps users record income and expenses, manage monthly budgets, monitor
savings goals, and understand spending patterns.

## Features

- Add, edit, and delete transactions
- Track total income, expenses, and current balance
- Search and filter transactions
- Filter transactions by date and type
- Export transaction history as CSV
- Monthly income and expense chart
- Expense breakdown by category
- Monthly budget tracking
- Smart spending insights
- Recurring income and expense management
- Savings goal tracker with contributions
- Dark Mode
- Responsive dashboard interface

## Technologies Used

### Frontend

- HTML5
- CSS3
- JavaScript
- Chart.js

### Backend

- Python
- FastAPI
- SQLModel
- SQLite
- Uvicorn
